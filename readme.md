# CGAF-GNN

This repository accompanies the paper **“Bridging Causality and Deep Learning for Dissolved Oxygen Reconstruction with a Causal Graph-Guided Adaptive Fusion Network (CGAF-GNN)”**.

It is intended to provide the CGAF-GNN model implementation, causal discovery scripts, and trained model weights for ocean dissolved oxygen (DO) reconstruction.

**Code availability:** The repository will be updated with the relevant code and model weights after the paper is submitted.
